CACADOR DE VAMPIROS

COMO EXECUTAR
1. Instale Python 3.
2. Abra o terminal nesta pasta.
3. Instale as dependencias: python -m pip install pygame pyttsx3 cx_Freeze
4. Execute: python main.py
5. Informe o nome no terminal; a janela abre depois disso.

CONTROLES
Setas: movimentar o cacador, um eixo por vez.
CTRL: disparar uma flecha.
R: recarregar ate 5 flechas.
ESPACO: pausar ou continuar.
X: iniciar ou tentar novamente.
X da janela: fechar o jogo.

PASTA BASES
Imagens, sons, icones e fonte ficam organizados em bases/.
As funcoes de pontuacao ficam em Recursos/trabalho.py.
