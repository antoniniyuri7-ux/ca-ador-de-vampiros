# Caçador de Vampiros

Projeto avaliativo desenvolvido em Python com Pygame para praticar a criação de jogos.

## Sobre o jogo

Controle um caçador, acerte os vampiros com flechas e tente fazer a maior pontuação. A partida termina quando um vampiro alcança o caçador.

## Como executar

Instale as bibliotecas:

```bash
